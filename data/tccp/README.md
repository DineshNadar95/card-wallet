# CFPB Terms of Credit Card Plans data

`cfpb_tccp-data_2025-12-31.xlsx`: the Jul–Dec 2025 release, downloaded from
https://files.consumerfinance.gov/f/documents/cfpb_tccp-data_2025-12-31.xlsx (US government
data). Committed because the CFPB site blocks downloads from CI runners. When a new release
comes out, replace the file (and the path in `.github/workflows/import-catalog.yml`).
